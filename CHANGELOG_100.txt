DS5 Light 1.0

## 추가한 기능

### 버튼 리매핑과 PC 프리셋
- 패드 그림에서 버튼을 선택하고 동작을 지정하는 리매핑 탭 추가
- PS·음소거를 포함한 버튼, 키보드 조합, 여러 패드 버튼을 함께 누르는 입력 조건 지원. PS 기존 단축키와 리매핑의 충돌 방지.

### Xbox 360 호환 모드
- Pico 입력을 가상 Xbox 360 패드로 전달하고 게임의 일반 진동을 Pico로 전달.
- Xbox 출력용 버튼별 터보(연타)·토글(유지), 지원되는 패드 출력의 스와이프·터치패드 클릭 설정.
- ViGEmBus·HidHide 확인, 사용자 동의 후 포함된 설치 파일로 설치·제거, 진행 로그와 문제 해결 창.
- DSX·DS4Windows 등과 번갈아 사용할 때 기존 HidHide 목록과 접근 허용 항목을 보존·복원.
- Watchdog 필요한 경우 문제 해결 창에서 상태 확인과 수동 제어.
- 업데이트 확인도 수동 실행 방식으로 정리하고 관리 작업의 중복 실행 방지.

### 입력 테스트와 사용 화면
- 기본/Xbox 모두 오디오햅틱 OFF에서 입력 테스트. 현재 패드 입력과 선택 Pico의 키보드 출력을 표시하며 일반 PC 키보드는 제외.
- 최근 입력을 최대 4줄로 표시하고 약 2.5초 뒤 순서대로 제거.
- 두 탭 공통 장치 조회·현재 프로필 표시·프로필 불러오기·오디오 시작/정지.
- Studio 폴링 설정, 자동 연결 해제 대기 시간/해제 안 함, 임시 적용 및 현재 프로필 저장.
- 작은 화면 스크롤, 팝업 중복 방지와 위치 조정, 설정값 라벨과 비활성 사유·도움말 개선.
- 장치 진단, 작업 진행·취소 안내, 리매핑 문제 해결 및 로그 확인 기능.

## 수정·안정성 보강
- 같은 장치의 일시 분리 후 30초 간격 재연결 대기. 재개 전 장치·게임·캡처 형식·RAM 오디오햅틱 상태를 재확인.
- 잘못된 장치 매칭, 게임 PID 재사용, 오디오 세션·채널 집계 및 설정 파일 검증 보완.
- 게임 전용 오디오 캡처 종료 실패를 완료로 취급하지 않고, 다음 캡처 전에 남은 프로세스·스레드 정리를 재시도.
- 앱 종료 단계 표시와 복구 실패 안내, 설치·업데이트·설정 작업 간 충돌 방지, 손상 설정 및 저장 실패 시 원본 보존.

## 최적화
- 필터의 작업 배열과 고정 계산값 재사용, 설정 캐시로 반복 할당·계산 감소. 필터 수식·계산 순서·자료형을 유지하고 float/PCM 동일성 검사.
- 필요할 때 필터를 준비하고, 필터 OFF→ON 재활성화 준비를 오디오 전송 처리와 분리.
