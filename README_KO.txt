DS5 Light 0.9.8

처음 사용하는 분: Studio 준비·슬롯 설정·PC 실행 안내 (SETUP_KO.md)를 먼저 읽어 주세요. 기존 Studio 사용자는 펌웨어를 다시 설치할 필요가 없습니다.

Windows 10/11 x64용 비공식 오디오햅틱 전처리기. Studio 펌웨어는 변경하지 않습니다.

실행
실행 배포 ZIP 전체를 풀고 DS5Light.exe를 실행합니다. 일반 오디오 출력은 그대로 두고 동글에 보내는 복사본을 처리합니다. 오디오를 녹음하거나 서버로 보내지 않습니다.

소리 받을 곳에서 장치 전체/선택한 게임만을 고릅니다. 실제 게임 exe를 선택하세요. 5.1채널 (홈시어터) 또는 2채널 (스테레오) 형식은 게임 내부 설정의 자동 감지 결과가 아닙니다. 장치 전체는 Windows 캡처 형식을 따르며 선택 게임은 정지 중 요청 형식을 지정합니다.
후방 LR/센터/LFE는 6ch에서 선택 합산합니다. 2ch에서는 비활성화됩니다. 대사 진동은 센터, 저음 BGM 진동은 LFE를 꺼서 비교할 수 있습니다. 초과분 자르기/부드러운 제한은 채널 합산 초과값의 처리 방식입니다.
PC 필터를 끄면 억제만 우회하며 채널 합산은 유지됩니다. 게임 기본 진동은 별도 기존 경로입니다.
게임별 프리셋은 사용자 LocalAppData의 DS5Light/presets.json에 저장됩니다. 장치 설정은 이 프로그램이 자동으로 변경하지 않습니다.

소스 빌드
Python 3.12 x64와 Windows .NET Framework C# 컴파일러가 필요합니다. PowerShell에서 build.ps1을 실행하면 의존성 설치, 테스트, 빌드 및 고지 수집을 진행합니다. 결과는 dist-0.9.8/DS5Light입니다. 순수 소스 실행은 필요한 의존성과 ProcessCapture.exe 빌드를 먼저 준비해야 합니다.

배포 조건
무료 사용·수정·무료 재배포는 허용합니다. 원본·수정판 판매 및 유료 제품·서비스에 포함은 별도 서면 허락이 필요합니다. 수익형 게임 방송에서 도구로 사용하는 것은 허용합니다. LICENSE.txt와 DISTRIBUTION_POLICY_KO.md를 보세요. 외부 구성요소는 원래 라이선스를 유지합니다. OSI 승인 오픈소스가 아닙니다.
Microsoft 런타임에는 THIRD_PARTY/upstream/Python-3.12.10-CRT-LICENSE.txt의 별도 조건이 적용됩니다. 해당 코드의 고지 변경, Microsoft 보증으로 오인시키는 표시, 비Microsoft 플랫폼 또는 악성·기만·불법 프로그램으로의 재배포를 허용하지 않습니다.

검증 및 한계
합성/모의 테스트는 실제 게임 체감이나 FPS 성능을 보장하지 않습니다. 특정 게임의 BGM·대사 완전 제거를 보장하지 않습니다. 현재 EXE는 미서명입니다.
공개 전 검토본입니다. 현재 아이콘의 원본 출처·재배포 권한은 확인되지 않았습니다. LICENSE.txt는 아이콘에 대한 권한을 허락하지 않습니다.

언어 선택 (0.9.0)
첫 실행은 Windows 표시 언어가 한국어면 한국어, 그 외에는 영어입니다. 오른쪽 위 한국어 / English에서 선택하면 다음 실행부터 적용됩니다. 재생 중 언어를 선택해도 오디오 스트림은 재연결하지 않습니다.
언어는 LocalAppData/DS5Light/ui.json에 별도로 저장되며 게임별 프리셋을 바꾸지 않습니다. 기존 한국어 프리셋도 불러올 수 있고 사용자가 붙인 슬롯 이름은 번역하지 않습니다.
영어 안내는 README.txt, 라이선스 영어 번역은 LICENSE_EN.txt입니다. 라이선스 해석은 기존 한국어 LICENSE.txt가 기준입니다.
선택한 게임만 캡처는 Windows 빌드 20348 이상에서 지원됩니다. 이전 Windows 10 빌드에서는 장치 전체 캡처를 사용하세요.
이번 변경은 UI 번역과 언어 설정만 추가했습니다. 0.8.7의 DSP·채널 합산·입출력 코드는 유지했습니다.

Studio 프리셋: Audio Haptics / DS Native 적용 안내 (studio-presets/README_KO.txt). 적용 전에 본인 설정을 백업하세요.

Studio 동글 슬롯 (0.9.8)
메인 화면 오른쪽 Studio 동글 설정에서 조회을 누르면 연결된 동글의 1~10번 이름을 읽습니다. 빈 슬롯은 Empty, 조회 불가능한 슬롯은 Unavailable로 구분합니다. 여러 장치가 있으면 대상 장치를 직접 선택하세요.
목록에서 고른 뒤 오디오를 정지하고 적용을 누르세요. 선택한 슬롯의 트리거·자이로 등 전체 설정이 적용되며, PC 게임별 프리셋은 바뀌지 않습니다. 슬롯 저장·덮어쓰기 및 자동 전환은 하지 않습니다.
Studio 포털에서 동시에 슬롯 작업을 하지 마세요. 응답 시간 초과는 적용 실패를 확정하지 못하므로 포털에서 현재 설정을 확인하세요. USB 재연결 필요 안내가 나오면 동글을 재연결한 후 다시 조회하세요.

Studio 진동 강도 (0.9.8)
프로그램을 열면 Studio 영역에서 현재 값을 한 번 읽습니다. 슬라이더에서 손을 놓으면 적용합니다. Studio Intensity 0~200%이며 PC 억제 강도와 별개입니다. 강도는 오디오 재생 중에도 적용할 수 있습니다.
현재 동글 설정만 바꾸며 저장된 슬롯은 덮어쓰지 않습니다. 다른 슬롯을 불러오면 해당 슬롯의 강도로 바뀝니다. 전원을 껐다 켠 뒤 유지되는 값으로 간주하지 마세요.
듀얼센스를 켜고 Studio 응답이 확인돼야 조작할 수 있습니다. Studio 영역 자체는 주기적으로 연결이나 강도를 조회하지 않습니다. 적용 시 응답 확인에 실패하면 비활성화합니다. 다시 켠 뒤 조회을 누르세요. 포털과 동시에 설정을 바꾸지 마세요.

네이티브 햅틱 / 적응형 트리거 (0.9.8)
메인 화면의 Studio 영역에서 현재 값을 자동으로 읽은 뒤 슬라이더로 조절합니다. 읽기나 적용에 실패하면 해당 조절을 사용할 수 없습니다. 현재 설정만 바꾸며 저장된 슬롯은 덮어쓰지 않습니다.
햅틱 전체 강도 (Gain) 조절: Studio 지원 범위 1.00~2.00배. 공통 Gain이므로 오디오햅틱 강도에도 영향을 줍니다. 1배 미만으로 낮추는 기능은 아닙니다.
적응형 트리거 강도 감소: 좌우 공통 0~10단계. 0은 추가 감소 없음, 10은 최대 감소 요청입니다. 효과 종류에 따라 감소가 약하거나 적용되지 않을 수 있습니다. 좌우 효과의 모양은 유지하며 힘을 줄이는 공통 설정을 보냅니다. 강도 백분율이나 효과의 완전한 끄기와는 다릅니다.
구형 Studio 펌웨어에서 지원 여부가 다를 수 있습니다. 적용 실패 시 현재 값을 다시 조회하세요. 0으로 돌아간 후 실제 복원 시점은 게임의 후속 트리거 출력에 따라 확인해야 합니다.

배터리 표시 (0.9.8)
메인 화면 아래에 Studio 배터리(10% 단위), 충전 상태, 마지막 조회 시각을 표시합니다. 앱 시작 후 한 번, 이후 배터리와 연결 확인을 모두 5분마다 수행합니다. 표시는 마지막 조회값이며, 연결·분리 반영이 최대 약 5분 늦을 수 있습니다. 표시를 클릭하면 즉시 새로고침합니다.
최소화 중에는 자동 조회를 쉽니다. 다시 열면 갱신 시각이 지난 경우 조회합니다. 조회 실패·연결 없음이면 이전 퍼센트를 숨깁니다. 여러 장치가 있으면 Studio 설정에서 장치를 고르세요. 설정 적용 시에는 별도로 응답을 확인하며, Studio Studio 영역 자체의 주기적 조회는 없습니다.
배터리 조회는 읽기 전용이며 오디오 처리 스레드 밖에서 실행합니다. 알림·애니메이션·배터리 로그 저장은 하지 않습니다. 포털의 동시 조회와 응답이 충돌하면 조회 실패로 표시될 수 있습니다.

프로세스 정렬 및 마지막 설정 (0.9.8)
게임 선택 아래 정렬에서 이름순 A–Z / CPU 사용률순을 고릅니다. CPU는 새로고침할 때 약 0.5초 동안 측정한 전체 논리 CPU 기준의 추정값이며 계속 감시하지 않습니다. 권한 부족이나 종료된 프로세스는 CPU —로 표시합니다. GPU 정렬은 이번 버전에 포함하지 않았습니다.
마지막 PC 옵션은 변경 후 잠시 기다리면 자동 저장하며, 정상 종료할 때도 저장합니다. 캡처 범위·게임 exe 이름·채널·입출력 장치·필터 옵션·정렬 방식·선택한 PC 슬롯·세부 화면 상태를 다음 실행 때 복원합니다. 프리셋 슬롯 파일과 별도인 LocalAppData/DS5Light/last_settings.json에 저장합니다.
실행 중인 게임을 같은 exe 이름으로 다시 찾습니다. 같은 이름이 여러 개면 직접 선택해야 하며, 이전 PID를 저장하거나 재사용하지 않습니다. 오디오는 시작 버튼을 눌러 실행합니다. Studio 슬롯·진동 강도는 자동 적용하지 않습니다. 손상된 설정 파일은 덮어쓰지 않으며, 초기화하려면 앱 종료 후 last_settings.json을 다른 이름으로 보관하세요.
언어 선택 옆에는 Language를 표시합니다. 언어 변경은 기존처럼 다음 실행부터 적용됩니다.

직접 강도 조절 (0.9.8)
마우스는 슬라이더에서 손을 놓을 때, 키보드는 마지막 키 조작 후 잠시 뒤에 한 번 적용합니다. 표시만 갱신하는 드래그 중에는 장치에 쓰지 않습니다. 같은 값은 다시 보내지 않으며 적용 후 값을 재조회합니다.
프로그램 시작·수동 조회·장치 선택·슬롯 적용 후 필요한 현재 값 읽기를 제외하고, 조작하지 않을 때 강도 통신은 없습니다. 배터리의 5분 조회는 유지합니다. 슬롯 적용 명령과 저장 방식은 변경하지 않았습니다.

현재 Studio 슬롯 표시 (0.9.8)
조회 시 현재 적용된 슬롯을 목록에서 선택합니다. 현재 설정이 슬롯 저장값과 다르면 수정됨을 표시합니다. 현재 슬롯을 확인하지 못하면 01번을 대신 선택하지 않으며 직접 선택해야 합니다. 조회만으로 슬롯을 적용하지 않습니다.

통합 화면 (0.9.8)
Studio 설정은 별도 창 대신 메인 화면 오른쪽에 표시합니다. 햅틱 전체 강도 (Gain) 조절 → 오디오햅틱 강도 → 적응형 트리거 강도 감소 순서입니다. Gain은 100~200%이며, 확인한 Studio 펌웨어는 200% 초과를 지원하지 않습니다. 300%를 전송하면 설정 검증에서 100%로 초기화되므로 범위를 늘리지 않았습니다.
DS5 Light 프리셋 저장·불러오기는 PC 캡처·채널·필터 설정만 대상으로 합니다. Studio Gain·Intensity·트리거 값과 Studio 슬롯 선택은 저장하거나 복원하지 않습니다. PC 프리셋을 불러오면 동글의 현재 값은 그대로입니다. Studio 슬롯을 직접 적용하면 해당 슬롯의 강도 값으로 바뀝니다.
배터리는 기존 5분 조회값을 4칸 그림과 숫자로 표시합니다. 1~25%=1칸, 26~50%=2칸, 51~75%=3칸, 76~100%=4칸입니다. 정보가 없으면 ?로 표시합니다. 그림을 눌러 새로고침할 수 있으며, 애니메이션이나 추가 폴링은 없습니다.
