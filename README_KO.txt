DS5 Light 0.9.1

처음 사용하는 분: Studio 준비·슬롯 설정·PC 실행 안내 (SETUP_KO.md)를 먼저 읽어 주세요. 기존 Studio 사용자는 펌웨어를 다시 설치할 필요가 없습니다.

Windows 10/11 x64용 비공식 오디오햅틱 전처리기. Studio 펌웨어는 변경하지 않습니다.

실행
실행 배포 ZIP 전체를 풀고 DS5Light.exe를 실행합니다. 일반 오디오 출력은 그대로 두고 동글에 보내는 복사본을 처리합니다. 오디오를 녹음하거나 서버로 보내지 않습니다.

소리 받을 곳에서 장치 전체/선택한 게임만을 고릅니다. 실제 게임 exe를 선택하세요. 5.1채널 (홈시어터) 또는 2채널 (스테레오) 형식은 게임 내부 설정의 자동 감지 결과가 아닙니다. 장치 전체는 Windows 캡처 형식을 따르며 선택 게임은 정지 중 요청 형식을 지정합니다.
후방 LR/센터/LFE는 6ch에서 선택 합산합니다. 2ch에서는 비활성화됩니다. 대사 진동은 센터, 저음 BGM 진동은 LFE를 꺼서 비교할 수 있습니다. 초과분 자르기/부드러운 제한은 채널 합산 초과값의 처리 방식입니다.
PC 필터를 끄면 억제만 우회하며 채널 합산은 유지됩니다. 게임 기본 진동은 별도 기존 경로입니다.
게임별 프리셋은 사용자 LocalAppData의 DS5Light/presets.json에 저장됩니다. 장치 설정은 이 프로그램이 자동으로 변경하지 않습니다.

소스 빌드
Python 3.12 x64와 Windows .NET Framework C# 컴파일러가 필요합니다. PowerShell에서 build.ps1을 실행하면 의존성 설치, 테스트, 빌드 및 고지 수집을 진행합니다. 결과는 dist-0.9.1/DS5Light입니다. 순수 소스 실행은 필요한 의존성과 ProcessCapture.exe 빌드를 먼저 준비해야 합니다.

배포 조건
무료 사용·수정·무료 재배포는 허용합니다. 원본·수정판 판매 및 유료 제품·서비스에 포함은 별도 서면 허락이 필요합니다. 수익형 게임 방송에서 도구로 사용하는 것은 허용합니다. LICENSE.txt와 DISTRIBUTION_POLICY_KO.md를 보세요. 외부 구성요소는 원래 라이선스를 유지합니다. OSI 승인 오픈소스가 아닙니다.
Microsoft 런타임에는 THIRD_PARTY/upstream/Python-3.12.10-CRT-LICENSE.txt의 별도 조건이 적용됩니다. 해당 코드의 고지 변경, Microsoft 보증으로 오인시키는 표시, 비Microsoft 플랫폼 또는 악성·기만·불법 프로그램으로의 재배포를 허용하지 않습니다.

검증 및 한계
합성/모의 테스트는 실제 게임 체감이나 FPS 성능을 보장하지 않습니다. 특정 게임의 BGM·대사 완전 제거를 보장하지 않습니다. 현재 EXE는 미서명입니다.
공개 전 검토본입니다. 현재 아이콘의 원본 출처·재배포 권한은 확인되지 않았습니다. LICENSE.txt는 아이콘에 대한 권한을 허락하지 않습니다.

언어 선택 (0.9.0)
첫 실행은 Windows 표시 언어가 한국어면 한국어, 그 외에는 영어입니다. 오른쪽 위 한국어 / English에서 선택하면 다음 실행부터 적용됩니다. 재생 중 언어를 선택해도 오디오 스트림은 재연결하지 않습니다.
언어는 LocalAppData/DS5Light/ui.json에 별도로 저장되며 게임별 프리셋을 바꾸지 않습니다. 기존 한국어 프리셋도 불러올 수 있고 사용자가 붙인 슬롯 이름은 번역하지 않습니다.
영어 안내는 README.txt, 라이선스 영어 번역은 LICENSE_EN.txt입니다. 라이선스 해석은 기존 한국어 LICENSE.txt가 기준입니다.
선택한 게임만 캡처는 Windows 빌드 20348 이상에서 지원됩니다. 이전 Windows 10 빌드에서는 장치 전체 캡처를 사용하세요.
이번 변경은 UI 번역과 언어 설정만 추가했습니다. 0.8.7의 DSP·채널 합산·입출력 코드는 유지했습니다.

Studio 프리셋: Audio Haptics / DS Native 적용 안내 (studio-presets/README_KO.txt). 적용 전에 본인 설정을 백업하세요.

Studio 동글 슬롯 (0.9.1)
메인 화면의 Studio 슬롯 → 조회 / 새로고침을 누르면 연결된 동글의 1~10번 이름을 읽습니다. 빈 슬롯은 Empty, 조회 불가능한 슬롯은 Unavailable로 구분합니다. 여러 장치가 있으면 대상 장치를 직접 선택하세요.
목록에서 고른 뒤 오디오를 정지하고 적용을 누르세요. 선택한 슬롯의 트리거·자이로 등 전체 설정이 적용되며, PC 게임별 프리셋은 바뀌지 않습니다. 슬롯 저장·덮어쓰기 및 자동 전환은 하지 않습니다.
Studio 포털에서 동시에 슬롯 작업을 하지 마세요. 응답 시간 초과는 적용 실패를 확정하지 못하므로 포털에서 현재 설정을 확인하세요. USB 재연결 필요 안내가 나오면 동글을 재연결한 후 다시 조회하세요.
